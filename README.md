# Тетрис

Классическая игра «Тетрис», реализованная на TypeScript + React + Vite.

## Стек

- **TypeScript** (strict mode)
- **React 18**
- **Vite**
- **ESLint** + **Prettier**
- Без сторонних зависимостей (кроме React)

## Особенности

- Поле 10×20 с видимой сеткой
- Все 7 фигур (I, O, T, S, Z, J, L) с уникальными цветами
- Призрачная фигура (ghost piece) — показывает, куда упадёт фигура
- Система уровней: каждые 10 линий скорость увеличивается
- Подсчёт очков с множителем уровня
- Превью следующей фигуры
- Пауза и рестарт
- Управление с клавиатуры

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Откройте `http://localhost:3000` в браузере.

## Сборка

```bash
npm run build
```

Производится оптимизированная сборка в папку `dist/`.

## Предпросмотр

```bash
npm run preview
```

## Разработка

```bash
npm run typecheck   # Проверка типов
npm run lint        # ESLint
npm run format      # Prettier (автоисправление)
npm run format:check # Проверка форматирования
```

## Управление

| Клавиша | Действие           |
| ------- | ------------------ |
| ← →     | Движение           |
| ↓       | Мягкое падение     |
| ↑ / X   | Поворот по часовой |
| Z       | Поворот против     |
| Пробел  | Hard drop          |
| P       | Пауза              |
| Enter   | Старт / Рестарт    |

## Очки

| Действие       | Очки          |
| -------------- | ------------- |
| Мягкое падение | +1 за клетку  |
| Hard drop      | +2 за клетку  |
| 1 линия        | 100 × уровень |
| 2 линии        | 300 × уровень |
| 3 линии        | 500 × уровень |
| 4 линии        | 800 × уровень |

## Структура проекта

```
src/
├── game/              # Чистая логика (без React)
│   ├── types.ts       # Типы
│   ├── constants.ts   # Константы
│   ├── tetromino.ts   # Генерация фигур
│   ├── board.ts       # Операции с полем
│   ├── collision.ts   # Коллизии
│   ├── rotation.ts    # Вращение
│   └── engine.ts      # Игровой движок
├── hooks/             # React-хуки
│   ├── useGameLoop.ts # Игровой цикл (requestAnimationFrame)
│   ├── useKeyboard.ts # Обработка клавиатуры
│   └── useTetris.ts   # Основная логика игры
└── components/        # UI-компоненты
    ├── Board.tsx      # Игровое поле
    ├── Cell.tsx       # Ячейка
    ├── NextPiece.tsx  # Превью следующей фигуры
    ├── ScorePanel.tsx # Панель счёта
    └── Controls.tsx   # Кнопки управления
```
