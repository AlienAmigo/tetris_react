# Архитектура проекта «Тетрис»

## Обзор

Приложение разделено на три независимых слоя:

1. **Игровая логика** (`src/game/`) — чистые функции, не зависят от React и браузера.
2. **React-хуки** (`src/hooks/`) — связывают игровую логику с React-компонентами.
3. **UI-компоненты** (`src/components/`) — отображение, без логики игры.

Такая архитектура позволяет тестировать игровую механику без React, а также легко менять UI, не затрагивая логику.

## `src/game/` — Игровая логика

Все функции чистые: не мутируют входные данные, возвращают новый объект `GameState`.

### `types.ts`

Определяет все типы, используемые в проекте:

| Экспорт         | Описание                                                                                                |
| --------------- | ------------------------------------------------------------------------------------------------------- |
| `CellValue`     | Тип ячейки: `0` — пустая, `1` — занятая                                                                 |
| `Position`      | Координаты `{ x, y }` для позиции фигуры                                                                |
| `TetrominoType` | Уникальный тип фигуры: `'I'`, `'O'`, `'T'`, `'S'`, `'Z'`, `'J'`, `'L'`                                  |
| `Tetromino`     | Фигура: тип, матрица вращения, цвет                                                                     |
| `GameState`     | Полное состояние игры: поле, текущая и следующая фигуры, счёт, уровень, линии, флаги паузы и конца игры |

### `constants.ts`

Константы, определяющие правила и баланс игры. Подробное описание ниже (см. раздел «Константы»).

### `tetromino.ts`

Генерация фигур:

| Экспорт                         | Описание                                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------------- |
| `createTetromino(type)`         | Создаёт объект `Tetromino` из типа. Возвращает `{ type, matrix, color }`                  |
| `getRandomType()`               | Возвращает случайный тип из 7. Используется для выбора следующей фигуры                   |
| `getSpawnPosition(matrixWidth)` | Вычисляет стартовую позицию по X, чтобы фигура появилась по центру поля (10 − ширина) / 2 |

### `board.ts`

Операции с игровым полем:

| Экспорт                  | Описание                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| `createEmptyBoard()`     | Создаёт поле 10×20, заполненное нулями                                                       |
| `clearFullLines(board)`  | Удаляет заполненные строки, добавляет пустые сверху. Возвращает `{ newBoard, linesCleared }` |
| `getDropInterval(level)` | Возвращает интервал авто-падения в мс для текущего уровня. Чем выше уровень, тем быстрее     |

### `collision.ts`

Проверка столкновений:

| Экспорт                                     | Описание                                                                                                                    |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `isColliding(matrix, position, board)`      | Проверяет, пересекается ли фигура с границами поля или занятыми ячейками. Возвращает `true`, если есть конфликт             |
| `getGhostPosition(matrix, position, board)` | Вычисляет, где фигура приземлится при hard drop. Возвращает позицию по Y, где фигура впервые коснётся дна или другой фигуры |

### `rotation.ts`

Вращение фигур:

| Экспорт                                               | Описание                                                                                                                                                                                                    |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rotateMatrix(matrix)`                                | Поворачивает матрицу на 90° по часовой стрелке                                                                                                                                                              |
| `rotateCounterClockwise(matrix)`                      | Поворачивает матрицу на 90° против часовой стрелки                                                                                                                                                          |
| `tryWallKick(matrix, position, board, kickDirection)` | При вращении у края поля фигура может «застрять». Эта функция пробует сдвинуть фигуру на 0, ±1, ±2 клетки по X, чтобы вращение прошло успешно. Если ни один сдвиг не подходит — возвращает исходную позицию |

### `engine.ts`

Центральный модуль — все операции над `GameState`:

| Экспорт                           | Описание                                                                                                                                           |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createInitialState()`            | Создаёт начальное состояние: пустое поле, сгенерированная следующая фигура, счёт = 0, уровень = 1                                                  |
| `spawnPiece(state)`               | Размещает следующую фигуру на поле как текущую. Если новая фигура не помещается — устанавливает `isGameOver: true`                                 |
| `moveLeft(state)`                 | Сдвигает фигуру на 1 клетку влево (если нет коллизии)                                                                                              |
| `moveRight(state)`                | Сдвигает фигуру на 1 клетку вправо                                                                                                                 |
| `moveDown(state)`                 | Сдвигает фигуру на 1 клетку вниз. Если уперлась — фиксирует фигуру на поле, очищает линии, начисляет очки. Возвращает `{ state, dropped, scored }` |
| `hardDrop(state)`                 | Мгновенно опускает фигуру до дна. Начисляет +2 очка за каждую пройденную клетку. Затем фиксирует и очищает линии                                   |
| `rotate(state, clockwise)`        | Поворачивает фигуру. Пробует wall kicks при столкновении                                                                                           |
| `togglePause(state)`              | Переключает флаг `isPaused`                                                                                                                        |
| `restart(state)`                  | Обнуляет всю игру, возвращает `createInitialState()`                                                                                               |
| `applyGravity(_state, deltaTime)` | Используется в игровом цикле для авто-падения с учётом времени                                                                                     |

## `src/hooks/` — React-слой

### `useGameLoop.ts`

Хук для игрового цикла на `requestAnimationFrame`:

| Параметр    | Описание                                                            |
| ----------- | ------------------------------------------------------------------- |
| `callback`  | Функция, вызываемая каждый кадр с `deltaTime` (мс с прошлого кадра) |
| `isRunning` | Флаг: `true` — цикл запущен, `false` — приостановлен                |

**Как работает:**

1. При изменении `isRunning` запускает или останавливает `requestAnimationFrame`.
2. Каждый кадр передаёт `deltaTime` в `callback`.
3. При размонтировании компонента автоматически отменяет анимацию (cleanup).

### `useKeyboard.ts`

Хук для обработки нажатий клавиш:

| Параметр    | Описание                                                                             |
| ----------- | ------------------------------------------------------------------------------------ |
| `onKeyDown` | Объект `{ [key]: handler }`, где `key` — код клавиши, `handler` — функция-обработчик |

**Как работает:**

1. Подписывается на `window.addEventListener('keydown', ...)`.
2. При нажатии ищет клавишу в `onKeyDown` и вызывает соответствующий обработчик.
3. Вызывает `event.preventDefault()` для игровых клавиш (стрелки, пробел), чтобы страница не скроллилась.
4. При размонтировании снимает обработчик.

### `useTetris.ts`

Основной хук, связывающий игровую логику с React:

**Состояния:**

- `gameState` — полное состояние игры (источник правды)
- `displayState` — состояние, передаваемое в компоненты (синхронизируется с `gameState`)
- `isStarted` — флаг: игра началась или ещё экран приветствия

**Как работает:**

1. При монтировании создаёт начальное состояние и спавнит первую фигуру.
2. `useGameLoop` вызывает `handleTick` каждый кадр.
3. `handleTick` накапливает `deltaTime` и вызывает `moveDown` каждые `dropInterval` мс.
4. `useKeyboard` подписывается на клавиши и вызывает соответствующие функции из `engine.ts`.
5. После фиксации фигуры автоматически спавнит следующую.
6. При game over или паузе цикл останавливается.

## `src/components/` — UI-слой

### `Board.tsx`

Отрисовка игрового поля 10×20:

1. Рендерит текущее состояние поля (`gameState.board`).
2. Поверх занятых ячеек рисует текущую фигуру (`gameState.currentPiece`).
3. Поверх всего рисует призрачную фигуру (ghost piece) — полупрозрачный контур, показывающий точку приземления.
4. Каждая ячейка — компонент `<Cell />`.

### `Cell.tsx`

Ячейка поля. Получает:

- `isFilled` — занята ли ячейка
- `color` — цвет заполненной ячейки
- `isGhost` — является ли ячейка частью призрачной фигуры

### `NextPiece.tsx`

Превью следующей фигуры. Рисует матрицу фигуры 2×2–4×4 в зависимости от типа.

### `ScorePanel.tsx`

Панель с тремя строками:

- **Счёт** — текущие очки
- **Уровень** — текущий уровень (1–20)
- **Линии** — общее число очищенных линий

### `Controls.tsx`

Две кнопки:

- **«Пауза / Продолжить»** — переключает паузу
- **«Рестарт»** — обнуляет игру и запускает заново

---

## `src/App.tsx`

Корневой компонент:

1. Вызывает `useTetris()` для получения состояния и обработчиков.
2. Рендерит `Board`, `ScorePanel`, `NextPiece`, `Controls`.
3. Показывает экран приветствия, если `isStarted === false`.
4. Показывает оверлей паузы, если `isPaused === true`.
5. Показывает оверлей game over с финальным счётом и кнопкой рестарта.

## Константы `src/game/constants.ts`

### Игровые размеры

| Константа      | Значение | Описание                                                     |
| -------------- | -------- | ------------------------------------------------------------ |
| `BOARD_WIDTH`  | `10`     | Ширина поля в клетках. Стандартное поле тетриса — 10 колонок |
| `BOARD_HEIGHT` | `20`     | Высота поля в клетках. Стандартное поле тетриса — 20 рядов   |

### Баланс скорости

| Константа               | Значение | Описание                                                                                                                                      |
| ----------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `INITIAL_DROP_INTERVAL` | `3000`   | Начальный интервал авто-падения в миллисекундах. Фигура падает на 1 клетку каждые 3 секунды на уровне 1. Чем ниже значение — тем быстрее игра |
| `MIN_DROP_INTERVAL`     | `150`    | Минимальный интервал авто-падения на максимальном уровне. Даже на 20-м уровне фигура не падает быстрее чем раз в 150 мс                       |
| `MAX_LEVEL`             | `20`     | Максимальный уровень. Скорость растёт линейно от `INITIAL_DROP_INTERVAL` до `MIN_DROP_INTERVAL` по мере набора уровней                        |
| `LEVEL_LINES_THRESHOLD` | `10`     | Количество линий, необходимых для повышения уровня. Каждые 10 очищенных линий = +1 уровень                                                    |

### Система очков

| Константа        | Значение | Описание                                          |
| ---------------- | -------- | ------------------------------------------------- |
| `LINE_SCORES[1]` | `100`    | Очки за очистку 1 линии (до умножения на уровень) |
| `LINE_SCORES[2]` | `300`    | Очки за очистку 2 линий одновременно              |
| `LINE_SCORES[3]` | `500`    | Очки за очистку 3 линий одновременно              |
| `LINE_SCORES[4]` | `800`    | Очки за очистку 4 линий одновременно (Tetris)     |

**Формула:** `очистка_линий × текущий_уровень`

### Цвета фигур

| Константа               | Значение  | Описание                    |
| ----------------------- | --------- | --------------------------- |
| `TETROMINO_COLORS['I']` | `#00f0f0` | Голубой — фигура I (палка)  |
| `TETROMINO_COLORS['O']` | `#f0f000` | Жёлтый — фигура O (квадрат) |
| `TETROMINO_COLORS['T']` | `#a000f0` | Фиолетовый — фигура T       |
| `TETROMINO_COLORS['S']` | `#00f000` | Зелёный — фигура S          |
| `TETROMINO_COLORS['Z']` | `#f00000` | Красный — фигура Z          |
| `TETROMINO_COLORS['J']` | `#0000f0` | Синий — фигура J            |
| `TETROMINO_COLORS['L']` | `#f0a000` | Оранжевый — фигура L        |

### Формы фигур

| Константа               | Значение    | Описание                                            |
| ----------------------- | ----------- | --------------------------------------------------- |
| `TETROMINO_SHAPES['I']` | 4×4 матрица | Палка: один ряд из 4 заполненных ячеек              |
| `TETROMINO_SHAPES['O']` | 2×2 матрица | Квадрат: все 4 ячейки заполнены                     |
| `TETROMINO_SHAPES['T']` | 3×3 матрица | Т-образная: средний ряд из 3, верхний — 1 по центру |
| `TETROMINO_SHAPES['S']` | 3×3 матрица | S-образная: верхний ряд [0,1,1], средний [1,1,0]    |
| `TETROMINO_SHAPES['Z']` | 3×3 матрица | Z-образная: верхний ряд [1,1,0], средний [0,1,1]    |
| `TETROMINO_SHAPES['J']` | 3×3 матрица | J-образная: средний ряд из 3, верхний — 1 слева     |
| `TETROMINO_SHAPES['L']` | 3×3 матрица | L-образная: средний ряд из 3, верхний — 1 справа    |

Каждая матрица — двумерный массив `number[][]`, где `1` = заполненная ячейка, `0` = пустая.
